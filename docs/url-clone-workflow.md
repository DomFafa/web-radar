# 网址建站与创建流程

## 用户流程

1. 创建项目时选择「模板建站」「网址 / 设计稿建站」或「AI 定制建站」。项目名称可留空。
2. 网址模式只需输入公开网址。新项目直接打开生成页，不要求用户准备截图、指定内页或上传素材。
3. 点击生成后，后台自动采集首页桌面与手机截图、识别主要内页、读取 DOM / CSS、导入可用图片与视频，然后使用项目已配置的视觉模型重建页面。
4. 默认只保存私有预览。品牌名称、有效联系邮箱在正式发布前补齐；自动发布需要用户主动勾选，并在任务开始前检查资料。
5. 预览与发布分为「内容与预览」「发布检查」「上线管理」。Banner 在内容区，SEO 与发布按钮在检查区，域名、发信账号、发布记录与发布任务在管理区。

编辑停止 1.5 秒后自动保存；切换步骤前也会保存。并发保存会排队，真实版本冲突保留原有对比合并流程。自动保存失败会明确显示错误，不无限重试；未保存内容仍有离开页面提示。进行中的克隆任务继续使用不可变输入快照，刷新、暂停、继续、停止仍由服务端控制。

Logo、Favicon、Banner、社交链接折叠为选填项。修改邮箱、电话、WhatsApp 保留已有定制设计，通过生成时保存的联系方式快照更新输出文本与链接；改变公司介绍、产品或设计方向仍会重置设计确认。网址模式在先预览、后补邮箱时，会将参考页面的邮件联系链接替换为站点自己的邮箱。

## 自动采集与安全边界

使用 [Cloudflare Browser Rendering Snapshot API](https://developers.cloudflare.com/api/resources/browser_rendering/subresources/snapshot/methods/create/)，需部署环境中的 `CLOUDFLARE_ACCOUNT_ID` 和具备 Browser Rendering 权限的 `CLOUDFLARE_API_TOKEN`。无需新增独立服务器。

- 首页采用 1440 和 390 像素视口；自动发现同源的产品目录、关于、联系页，各采集桌面截图。当前最多 4 个主要页面，不是无限爬取整站。
- 先读取公开 HTML 与样式，再用隔离浏览器截图。资源来源经过公网 DNS 检查，浏览器仅放行已检查的资源来源。
- HTTP 重定向逐跳校验；拒绝本机、内网、异常端口、URL 中的用户名密码。不向参考站点转发应用或模型密钥。
- 原始 HTML 最大 1 MiB；每页最多 4 个外部样式文件，每个 300 KB；单次截图响应最大 12 MiB；素材最多 24 个、48 次尝试，单素材 24 MiB、累计 48 MiB；采集阶段上限 4 分钟。
- 支持导入 PNG、JPEG、WebP、GIF、MP4、WebM，并检查文件签名。外部 SVG、字体、脚本不直接发布；内联结构供模型参考。超过限制或素材不可读会展示提示。
- 截图与 DOM/CSS 上下文保存在私有对象存储。只有导入的图片和视频进入克隆站点的可发布素材清单；切换到其他建站模式不会公开这些参考素材。
- 采集记录和生成结果由服务端维护，普通草稿保存不能伪造。源码脚本不会直接注入新网站；参考内容作为不可信数据交给模型，生成文件仍经过原有校验与净化。
- 首页无法读取、需要登录或访问验证时，明确报错，不用演示页替代。内部页面采集失败会保留提示。不会自动登录或绕过验证。

## 状态与验证

进度分为网址采集、图片读取、模型输出、页面校验与可选发布。采集展示实际截图数，模型展示实际返回字符数；预计时间是估算，不伪造模型完成百分比。

“页面代码已生成”只表示代码已保存，**不等于像素还原已验收**。自动多尺寸检查沿用现有渲染服务；没有该服务或检查失败时，会保留真实状态。桌面/手机字体、图片裁切、动画和动态交互仍需要在私有预览中对照原站检查。

回归覆盖：URL 页面发现、桌面/手机截图、图片/视频导入、公网访问限制、暂停边界、素材发布权限、联系方式更新；浏览器覆盖只填网址生成预览、刷新恢复、自动保存、完成后停止轮询、暂停继续、显式自动发布及发布前资料检查。浏览器中的模型与截图 API 使用明确的测试替身，不以测试页面声称真实模型达到 1:1。
