# Bundled typeface

`nunito-latin.woff2` is the unmodified Nunito variable font (weights 400–900), Latin subset, served by Google Fonts v32. Source: https://fonts.gstatic.com/s/nunito/v32/XRXV3I6Li01BKofINeaBTMnFcQ.woff2

SIL Open Font License 1.1 is included as `OFL-Nunito.txt`, retrieved from https://github.com/google/fonts/tree/main/ofl/nunito. Emitted pages embed this font as data only when the template requests `data-wr-font="rounded"` and uses `WR Rounded`; website visitors make no font network requests.
